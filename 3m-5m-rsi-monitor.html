This alert is independent of the Potential Buy Setups. Negative MACD is defined here strictly as the MACD histogram (DIF − DEA) being below zero. The alert uses the current forming 5-minute candle.

RSI uses Wilder's smoothing (default period 14) and includes the currently forming Binance candle, so values can change before candle close. MACD also evaluates the currently forming candle. This page is standalone and does not share code, state, workers, or API polling with the MACD scanner.
