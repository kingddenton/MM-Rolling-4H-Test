Rolling 4H, 6H and 12H changes = (latest price − reference price) ÷ reference price × 100. Each reference is the close of the latest completed 1-minute candle at or before its lookback timestamp, so it can be up to one minute older than the exact target. 24H change is Binance's rolling 24-hour ticker value.
